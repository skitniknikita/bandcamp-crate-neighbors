# Support — Crate Neighbors for Bandcamp

Report a bug, ask for help, or suggest a feature in [GitHub Issues](https://github.com/skitniknikita/bandcamp-crate-neighbors/issues). English and Russian are welcome.

Please include your Chrome version, extension version, what you expected, what happened, and the steps needed to reproduce it. A public Bandcamp release URL can help if the problem is specific to one page.

GitHub Issues are public. Do not attach passwords, cookies, authentication tokens, private account data, full browser logs, or screenshots you do not want published. Crop screenshots to the relevant interface.

## Common questions

**A shared-purchase count says ≥ 1.** This is a lower bound from the collection sample checked so far. Use **Check full counts** while signed into the connected Bandcamp account, or check the collection deeper.

**The queue paused.** Read the reason in the panel. Wait for a cooldown; for a browser check, open Bandcamp and complete it, then resume. A request already in progress may finish before a manual pause takes effect.

**A custom shop domain does not work.** Version 0.1.1 supports bandcamp.com and its subdomains. Open a supported Bandcamp URL when available.

**I cannot find the extension in Chrome Web Store.** The listing is not available yet. Install the ZIP from [Releases](https://github.com/skitniknikita/bandcamp-crate-neighbors/releases/latest) as an unpacked extension.

**I want to remove my data.** Uninstall the extension at chrome://extensions. Hidden results can be restored in its settings.

## По-русски

Оставьте вопрос или сообщение об ошибке в [GitHub Issues](https://github.com/skitniknikita/bandcamp-crate-neighbors/issues). Укажите версии Chrome и расширения, ожидаемый результат и шаги воспроизведения.

Обсуждения публичные. Не прикладывайте пароли, cookies, токены авторизации и личные данные. Для проблемы со страницей достаточно публичной ссылки на релиз.

Знак «≥» означает число совпадений, уже найденных в выборке. Полный счётчик Bandcamp проверяется при входе в подключённый аккаунт. При паузе очереди сначала прочитайте причину в интерфейсе.
