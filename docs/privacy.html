Crate Neighbors for Bandcamp — Privacy policy

Effective date: October 31, 2026. Applies to version 0.1.1 of the Chrome extension and this product website.

Extension

Crate Neighbors for Bandcamp is an independent Chrome extension for music and collector discovery. It has no developer backend, analytics, subscription, or separate account system.

Data handled. The extension reads Bandcamp profile URLs and IDs, display names and pictures, purchases and wishlist metadata, followed collectors, public supporters, and release titles, artists, artwork and URLs. It uses these data to compare collections, exclude known releases and explain recommendations.

Local storage. Collections, results, the scan queue and hidden items are stored in browser IndexedDB. Language settings are stored in Chrome extension local storage. Connected profiles have separate data. Chrome cloud sync is not used.

Network. Extension requests go to Bandcamp over HTTPS. Artwork can load from Bandcamp's CDN. The platform receives ordinary requests needed to provide its pages and data. Collections, match results and usage events are not uploaded to the publisher, GitHub or analytics providers.

Authentication. Requests may use the existing browser session with Bandcamp. The extension does not ask for your password, use the cookies API, or persist authentication cookies or authentication tokens. It does not store raw HTML, purchased-music download URLs or payment details.

Retention. Cached collector data can be reused for up to 24 hours before being fetched again. Your library, results, scan queue, settings and hidden choices remain locally for your use. Expiring a cache does not remove hidden choices.

Full shared-purchase counts. A full count shown by Bandcamp is trusted only when the current signed-in account matches the connected profile. It is stored with that profile and excluded from the shared collector cache. Other profiles use matches observed in the checked sample.

User actions. You start, pause and resume scans. Listening, purchases and following take place on pages opened on the music platform. The extension does not perform those actions automatically.

Deletion. Uninstall the extension at chrome://extensions to remove its local data. Settings also let you restore hidden items and request a cache refresh.

Data use. Data is used only for the music-discovery feature. It is not sold or used for advertising, credit decisions, analytics or unrelated transfers.

Website and support

This static product website is hosted on GitHub Pages. It adds no analytics scripts, tracking cookies, advertising or collection-upload forms. GitHub processes hosting requests under its own privacy statement.

Support is provided through GitHub Issues. Information you choose to post there is public and is handled by GitHub. Do not post passwords, authentication cookies or tokens, private account information, or screenshots you do not want published.

Questions about this policy can be raised through the same support channel.

Политика приватности

Дата: 31 октября 2026 года. Применяется к расширению версии 0.1.1 и сайту продукта.

Crate Neighbors for Bandcamp — независимое расширение Chrome для поиска музыки и коллекционеров. Собственного сервера, аналитики, подписки и отдельной регистрации у расширения нет.

Какие данные обрабатываются. Адреса и идентификаторы профилей, имена и изображения, сведения о покупках, wishlist и подписках на людей, публичные покупатели релизов, названия, артисты, обложки и ссылки. Они нужны для сравнения коллекций, исключения уже знакомой музыки и объяснения рекомендаций.

Локальное хранение. Коллекции, результаты, очередь и скрытия сохраняются в IndexedDB браузера; язык — в локальном хранилище расширения Chrome. Данные подключённых профилей разделяются и не синхронизируются через облако Chrome.

Сеть. Запросы расширения идут к Bandcamp по HTTPS; обложки могут загружаться с его CDN. Коллекции, совпадения и события использования не отправляются издателю, в GitHub или в сервисы аналитики.

Авторизация. Запросы могут использовать существующую сессию Bandcamp в браузере. Расширение не спрашивает пароль, не использует cookies API и не сохраняет cookies или токены авторизации. Исходный HTML, ссылки скачивания купленной музыки и платёжные данные не записываются в хранилище.

Срок хранения. Кеш чужих коллекций используется до 24 часов перед повторным запросом. Собственная коллекция, результаты, очередь, настройки и скрытия сохраняются для использования в браузере. Истечение срока кеша не удаляет пользовательские скрытия.

Счётчики покупок. Полный счётчик Bandcamp используется только при совпадении текущего аккаунта и подключённого профиля. Он хранится в данных этого профиля и не включается в общий кеш коллекций. Для другого профиля используются совпадения, найденные в проверенной выборке.

Действия и удаление. Поиск запускается, приостанавливается и продолжается пользователем. Прослушивание, покупка и подписка происходят на странице музыкальной платформы. Удаление расширения через chrome://extensions удаляет его локальные данные; скрытые результаты можно восстановить в настройках.

Использование данных. Данные используются только для поиска музыки. Они не продаются, не используются для рекламы, оценки кредитоспособности, аналитики и посторонних передач.

Сайт и поддержка. Этот статический сайт размещён на GitHub Pages. Мы не добавляем аналитику, отслеживающие cookies, рекламу или формы загрузки коллекций. Запросы к хостингу обрабатываются GitHub по его политике приватности.

Поддержка работает через GitHub Issues. Обсуждения публичные. Не публикуйте там пароли, cookies, токены авторизации и личные данные. Вопросы по этой политике можно задать в том же канале.
